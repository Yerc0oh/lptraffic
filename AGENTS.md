# AGENTS.md

Streamlit academic prototype (Spanish UI/docs) for synthetic traffic prediction and route optimization in La Paz. Not live traffic data.

## Setup and commands

Run from the repo root so `src`, `views`, and `scripts` import correctly.

```bash
python -m venv venv
venv\Scripts\activate            # Windows; use source venv/bin/activate on Linux
python -m pip install -r requirements.txt
python -m streamlit run app.py   # http://localhost:8501
python -m pytest -q              # full suite
python -m pytest tests/test_genetic_algorithm.py::test_optimization -q
python -m scripts.train_models --epochs 35   # rewrite models + metadata
python -m scripts.generate_dataset           # rewrite all data/*.csv
```

- Target Python is **3.11**; `iniciar_windows.bat` requires `py -3.11`. A working `venv/` is present; use `venv\Scripts\python -m ...`. The system `python` is 3.14 without the project dependencies, and its sklearn cannot load the bundled models.
- Version locking matters: the bundled models were trained with **scikit-learn 1.8.0**; `src/neural_network.load()` rejects any other sklearn version. `requirements.txt` pins the exact versions—use the venv.
- `scripts.train_models` defaults to 100 epochs, but the included models used `--epochs 35`. It validates both CSVs, trains classifier and regressor, evaluates on the independent test CSV, and writes model files + `models/training_metadata.json`.
- `scripts.generate_dataset` overwrites `traffic_dataset.csv`, `traffic_test.csv`, `road_nodes.csv`, and `road_edges.csv` (100k seed 42; 5k seed 43 for 2026). Any dataset change invalidates existing models.
- No lint/format/typecheck config or CI exists. Verification = pytest + launching the app.

## Architecture

- `app.py` only wires six page modules from `views/`; page presentation logic lives in `views/*.py`, reusable domain logic in `src/`.
- Sidebar navigation is button-based (`st.session_state.page`, keys `nav_<page>`), not a radio. Active page styling comes from `type='primary'` plus `assets/styles.css`.
- The sand/terracotta palette is duplicated by necessity: Streamlit theme in `.streamlit/config.toml`, CSS variables in `assets/styles.css`, and Python constants in `src/config.py`. Plotly charts use the global `lptraffic` template applied by `src/theme.py`; update all four when changing colors.
- `src/config.py` is the single source for paths, `SEED=42`, `FEATURES`, `COLUMNS`, classes, and colors. Change feature lists there.
- Data flow: `data_loader.validate` → chronological ~80/20 `split` → `preprocessing.transformer` (fit on train only) → per-epoch `partial_fit` → best weights by macro-F1/MAE → Joblib bundle.
- `FEATURES` deliberately excludes observed outcomes (`nivel_trafico`, `tiempo_recorrido_min`, `indice_congestion`, flow/speed/id/date). Do not add them; `tests/test_preprocessing.py` guards leakage.
- `src/traffic_graph.py` is the real source of the road network (`NODES`/`LINKS`); `data/road_*.csv` are generated by `write_network()`. Network edits require regenerating data and retraining.
- Route optimization builds Prediction-derived edge weights, removes blocked edges, and compares a custom genetic algorithm against Dijkstra. Dijkstra is optimal for fixed positive additive weights; do not claim the GA beats it.
- Models are tied to a dataset fingerprint (`dataset_hash`); a regenerated/uploaded dataset requires retraining both models. The UI enforces this in `src/utils.compatible_models`.
- Optional Folium base map needs internet; Plotly schematics work offline.

## Data and test gotchas

- `validate()` is strict: exact 26 columns, no missing required values, no duplicates, temporal flags consistent, `tramo_id` must exist in `road_edges.csv`, and road attributes must match the network CSV. Blocked rows are the only valid place for NaN time, with speed 0.
- Do not hand-edit generated CSV/model artifacts as the fix; change the generator/training code and regenerate.
- `tests/test_dataset.py` asserts exact packaged sizes (100,000 / 5,000) and date ordering.
- `tests/test_genetic_algorithm.py::test_real_models_end_to_end` loads the bundled Joblib models, so it fails unless sklearn matches 1.8.0 and `models/*.joblib` exist.
- `tests/test_neural_network.py` trains tiny synthetic models for speed; no external services are needed.
- Python is a `.py`-only project; no migrations or build step.
- Keep user-facing text and documentation in Spanish.
- Never load third-party Joblib files: deserialization is unsafe.
